# Codeforces Solutions

Solutions accepted under the Codeforces handle `yaduvendukunal` are stored here. The importer keeps the latest accepted solution for each problem and defers submissions from contests that are still active.

The GitHub Actions workflow performs an initial import, then checks daily for new accepted solutions. To run it manually, open the **Actions** tab, select **Import Codeforces solutions**, and choose **Run workflow**.
