# Codeforces Solutions

Solutions accepted under the Codeforces handle `yaduvendukunal` are imported here. The importer keeps the latest accepted solution for each problem and avoids publishing submissions from contests that are still active.

The GitHub Actions workflow runs once per day and can also be started manually from the **Actions** tab. It uses the repository Actions secrets `CODEFORCES_API_KEY` and `CODEFORCES_API_SECRET` to request source code from the official Codeforces API.
